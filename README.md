# BeatJump-Size-Stepper-Serato-DJ-Pro-Midi-Map-
A Serato DJ Pro MIDI map that lets you change the beat jump size with just two pads per deck: one steps the size down, the other steps it up. Forward and backward jump pads are included, and the pads change color to show when you've reached the end of the range.  Made for the Pioneer DJ DJM-S9 and DJM-S11.
